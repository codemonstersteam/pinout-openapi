# sandbox — проверка алгоритма pinout-openapi

Живой эксперимент рядом с BR ([`../TASK.md`](../TASK.md)): доказывает, что постановка корректна, до всякой
реализации на Go. **Идея одной фразой:** из стаба поставщика в компонентных тестах потребителя
восстанавливаем маленький кусок OpenAPI (что потребитель шлёт и что читает) и сверяем его со спекой
поставщика — поле-в-поле, без запуска сервисов.

## Запуск

```
npm install && node check.mjs      # единственная зависимость — js-yaml (спеки в YAML, как в проде)
```

## Что внутри

```
provider/openapi.v1.yaml                     — «репа-поставщик»: master-спека balance-service (истина)
consumer/
  contract-tests.yaml                        — «репа-потребитель» (из скафолда): какие операции зовёт
  component-tests/provider-stub.yaml         — стаб поставщика в компонентных тестах (примеры запрос/ответ)
scenarios/                                    — мутации спеки поставщика (по одной на файл):
  v2a-added-optional-response.yaml           —  +необязательное поле ответа   → ожидаем ✅
  v2b-removed-response-field.yaml            —  −поле ответа (currency)        → ожидаем ❌  (ключевой кейс)
  v2c-added-required-request.yaml            —  +обязательное поле запроса     → ожидаем ❌
  v2d-type-drift.yaml                        —  смена типа (integer→string)    → ожидаем ❌
check.mjs                                     — референс-чекер (функциональный стиль, js-yaml)
ALGORITHM.md                                  — алгоритм как композиция чистых функций (доступно)
EXPERIMENT.md                                 — логический вывод: гипотеза → правило → факт, 5/5 сходится
```

## Результат

`check.mjs` даёт 5/5 совпадений вердикта с гипотезой (см. `EXPERIMENT.md`). Ядро проверки — два вложения
множеств: `requires(provider) ⊆ sends(consumer)` (запрос, контравариантно) и
`reads(consumer) ⊆ provides(provider)` (ответ, ковариантно) + совпадение типов. Именно `reads ⊆ provides`
ловит удаление поля, которое наивная валидация примера на открытой схеме пропустила бы.

> Это песочница-доказательство логики. Прод-инструмент — Go + `kin-openapi` (parse, `$ref`, рекурсивный
> субтайпинг схем), вход — `consumed-contract` из E-harness с provenance. Соответствие — в `ALGORITHM.md`.
