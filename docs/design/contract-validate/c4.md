# C4 — концептуальный дизайн pinout-openapi

Уровни C4 для среза `validate-contract`. Диаграммы на Mermaid — рендерятся прямо в GitHub (блок ` ```mermaid `, без плагинов). C1 (System Context экосистемы) — в [концепте pinout](../../../../pinout/README.md). C4 (код) не рисуем — это сигнатуры в [`impl-brief-01.md`](./impl-brief-01.md).

## C2 — Container

Один развёртываемый юнит (CLI-бинарь) + библиотека `kin-openapi` (honest reuse).

```mermaid
C4Container
    title pinout-openapi — Container
    Person(ci, "CI / разработчик", "")

    System_Boundary(s, "pinout-openapi") {
        Container(cli, "CLI-бинарь", "Go + cobra", "validate <config>; единственный исполняемый юнит")
        Container_Ext(kin, "kin-openapi", "Go-библиотека", "парсинг и резолв $ref OpenAPI 3.x")
    }

    ContainerDb(cfg, "contract-tests.yaml + спека потребителя", "файл / ФС", "конфиг пары и локальная спека")
    System_Ext(git, "Git / HTTP сервер", "master-OpenAPI поставщика (= прод)")
    System_Ext(netlist, "pinout-netlist", "потребитель отчётов")

    Rel(ci, cli, "validate <config>", "CLI")
    Rel(cli, kin, "использует", "in-process")
    Rel(cli, cfg, "читает", "файл")
    Rel(cli, git, "fetch master-спеки", "HTTP")
    Rel(cli, netlist, "JSON-отчёт (канон)", "stdout / файл")
```

## C3 — Component (= дерево модулей среза `validate-contract`)

Зависимости направлены внутрь: ингресс → head → {логика, I/O}. Логика не знает о cobra/http/os/time; I/O реализует интерфейсы, объявленные в head.

```mermaid
C4Component
    title pinout-openapi — Component (срез validate-contract)

    Container_Boundary(cli, "CLI-бинарь") {
        Component(ingress, "cmd validate (cobra)", "ингресс", "парсит аргумент; исход → exit code 0/1/2/3")
        Component(head, "ValidateContract", "head — ROP-труба", "линейная оркестрация, без бизнес-ветвлений")

        Component(domain, "domain", "логика: конструкторы", "NewConfig / NewOperationKey / NewContractValidate — невалидный вход не собирается")
        Component(compare, "compare", "логика: чистое сравнение", "ValidateOperations + findProviderOperation / compareRequest / Responses / StatusCodes / ContentTypes / Schemas")

        Component(cfgstore, "ConfigStore", "I/O", "чтение YAML")
        Component(specclient, "SpecClient", "I/O", "file/URL + kin-openapi, резолв $ref")
        Component(writer, "ReportWriter", "I/O", "ToReportDTO → канонический JSON (stdout+файл)")
        Component(clock, "Clock", "I/O", "Now → generated_at")
    }

    System_Ext(kin, "kin-openapi", "библиотека")

    Rel(ingress, head, "вызывает")
    Rel(head, cfgstore, "Load(path)")
    Rel(head, domain, "NewConfig / NewContractValidate")
    Rel(head, specclient, "Fetch ×2 (consumer, provider)")
    Rel(head, compare, "ValidateOperations")
    Rel(head, writer, "Write(report, cfg)")
    Rel(specclient, kin, "использует")
    Rel(writer, clock, "Now()")
    Rel(compare, domain, "использует типы")
```

**Поток по трубе head:** `cmd` → `ValidateContract` → `ConfigStore.Load` → `NewConfig` → `SpecClient.Fetch ×2` → `NewContractValidate` → `ValidateOperations` → `ReportWriter.Write` → exit code. Первый `Err` (конфиг/спека) коротит трубу; несовместимость — это `Report` с `compatible=false`, не `Err`. Подробности — [`slices/01-validate-contract.md`](./slices/01-validate-contract.md).
