# intent — contract-validate

По `contract-tests.yaml` определить, совместим ли потребитель с master-OpenAPI поставщика, и вернуть вердикт + структурированный отчёт.

- **Вход:** путь к `contract-tests.yaml`.
- **Выход:** вердикт совместимости (exit code) + JSON-отчёт в общем формате экосистемы.
- **Природа:** чистая функция сравнения двух спек (без подъёма заглушек и прогона тестов).
- **Контракт инструмента:** CLI `validate <config>` + схема `contract-tests.yaml` (см. README).
- **Эпик:** E1 в [бэклоге экосистемы](../../../../pinout/backlog.md).
