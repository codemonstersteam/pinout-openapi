## C3 — Component (= the module tree)

Dependencies point **inward**: `cli` → `head` → {`config`, `spec`, `compare`, `report`}. The pure core
(`compare`, `config` constructors) knows nothing of cobra/http/os/kin-openapi; the four I/O objects are
the only externally-connected components and implement the port interfaces the head declares.

```mermaid
C4Component
    title pinout-openapi — Component (slice compat-check)
    Container_Boundary(app, "pinout-openapi CLI") {
        Component(cli, "cli (Parse/Exit)", "ingress — io: none", "cobra: flags/args to Request; Result to exit 0/1/2/3 + stdout/stderr")
        Component(head, "ProcessCompatCheck", "head — ROP pipe, io: none", "linear orchestration, no business branching")
        Component(cfg, "config (NewConfig + VOs)", "logic — io: none", "validate config; illegal states unrepresentable")
        Component(compare, "compare (5 rules + verdict)", "logic — io: none", "presence, request_contravariance, response_covariance, status_codes, content_types; buildReport")
        Component(cfgrd, "ConfigReader", "I/O — io: file", "pipe — no transformations")
        Component(consrd, "ConsumerSpecReader", "I/O — io: file", "pipe — kin-openapi load")
        Component(provrd, "ProviderSpecReader", "I/O — io: http", "pipe — HTTP GET or file + kin-openapi load")
        Component(repwr, "ReportWriter", "I/O — io: file", "pipe — write JSON file + stdout line")
    }
    System_Ext(kin, "kin-openapi", "OpenAPI 3.x parse + $ref resolve")
    System_Ext(providersrv, "Provider spec host", "HTTP(S), unauthenticated")
    System_Ext(fs, "Filesystem", "config, consumer spec, report")
    Rel(cli, head, "calls with Request")
    Rel(head, cfgrd, "Read(configPath)")
    Rel(head, cfg, "NewConfig(raw)")
    Rel(head, consrd, "Load(consumer.spec_path)")
    Rel(head, compare, "NewCheckedOperations / Compare")
    Rel(head, provrd, "Load(provider.source)")
    Rel(head, repwr, "Write(report, settings)")
    Rel(cfgrd, fs, "reads")
    Rel(consrd, fs, "reads")
    Rel(consrd, kin, "parses with")
    Rel(provrd, providersrv, "GET (bounded by timeout)")
    Rel(provrd, kin, "parses with")
    Rel(repwr, fs, "writes")
```

**Head-pipe flow** (from `module-tree.md`):

```
cli.Parse → ProcessCompatCheck → ConfigReader.Read → NewConfig → ConsumerSpecReader.Load
  → NewCheckedOperations → ProviderSpecReader.Load → NewComparison → Compare → ReportWriter.Write → cli.Exit
```
