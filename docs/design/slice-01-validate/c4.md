## C3 — Component (= module tree)

Dependencies point **inward**: ingress → head → {logic, I/O}. Logic knows nothing of cobra / http /
os / time; the I/O objects are the only externally-connected components (pipes — no transformations).

```mermaid
C4Component
    title pinout-openapi — Component (slice-01-validate, C3 = module tree)
    Container_Boundary(app, "pinout-openapi validate") {
        Component(parse, "cli.Parse", "ingress (io: none)", "argv -> Invocation DTO; parse only")
        Component(head, "ProcessValidate", "head — ROP pipe (io: none)", "linear orchestration, no branching")
        Component(exit, "cli.ResolveExitCode", "adapter (io: none)", "Result -> exit 0/1/2/3 + stdout")
        Component(cfgstore, "ConfigStore.Load", "I/O (io: none — fs pipe)", "pipe — no transformations")
        Component(newcfg, "NewConfig", "logic: constructor (io: none)", "valid-by-construction Config")
        Component(ctrstore, "ContractStore.Load", "I/O (io: none — fs pipe)", "pipe — no transformations")
        Component(specload, "SpecLoader.Load", "I/O (io: http)", "pipe — kin-openapi acquire + parse")
        Component(newcmp, "NewComparison", "logic: constructor (io: none)", "unite scoped ops + consumed + spec")
        Component(derive, "DeriveProviderOperation", "logic: R1 (io: none)", "navigate spec; requires/provides")
        Component(cmpop, "CompareOperation", "logic: R2/R3/R4 (io: none)", "requires subset sends; reads subset provides; types")
        Component(cmpc, "CompareContracts", "logic: fold (io: none)", "concatMap violations + uncovered")
        Component(fold, "FoldReport", "logic (io: none)", "outcome -> report.schema DTO")
        Component(writer, "ReportWriter.Write", "I/O (io: none — fs pipe)", "pipe — write JSON report")
    }
    System_Ext(fs, "Local filesystem", "config / consumed-contract / spec_path / report")
    System_Ext(provider, "Provider OpenAPI (spec_url)", "HTTPS + Bearer")
    Rel(parse, head, "Invocation")
    Rel(head, cfgstore, "Load")
    Rel(head, newcfg, "NewConfig")
    Rel(head, ctrstore, "Load")
    Rel(head, specload, "Load")
    Rel(head, newcmp, "NewComparison")
    Rel(head, cmpc, "CompareContracts")
    Rel(head, fold, "FoldReport")
    Rel(head, writer, "Write")
    Rel(cmpc, derive, "per operation")
    Rel(cmpc, cmpop, "per operation")
    Rel(head, exit, "Result")
    Rel(cfgstore, fs, "read", "os")
    Rel(ctrstore, fs, "read", "os")
    Rel(specload, fs, "read spec_path", "os")
    Rel(specload, provider, "GET spec_url", "HTTPS")
    Rel(writer, fs, "write report", "os")
```

**Head-pipe flow** (from `module-tree.md`):

```
cli.Parse -> ProcessValidate -> ConfigStore.Load -> NewConfig -> ContractStore.Load
  -> SpecLoader.Load -> NewComparison -> CompareContracts{DeriveProviderOperation, CompareOperation}
  -> FoldReport -> ReportWriter.Write -> cli.ResolveExitCode -> (exit code, stdout JSON)
```
